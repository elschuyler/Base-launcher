# Vian Launcher - Development Plans

This repository maintains the following technical design and roadmap plans:

1. **[App Lock Implementation Plan](APP_LOCK_PLAN.md)**:
   - Complete technical architecture, database schema migrations (Room v5 to v6), biometric & phone PIN authentication flow, custom passcode tier, launcher-level interception, and phased roadmap for locking apps and protecting hidden apps.

2. **[Gestures, Actions & Popup Widgets Plan](GESTURES_AND_ACTIONS_PLAN.md)**:
   - 5 Item Gestures (Double tap, Swipe up/down/left/right), curated system actions (lock screen, mute volume, mute ringtone, notifications, quick settings, app drawer, folder popup), Option C on-demand popup widgets, Add to Home bottom sheet, dedicated GesturesActivity page, unified Backup & Restore, and LogCatcher integration across 5 implementation phases.

3. **[Architecture & Migration Blueprint](BLUEPRINT.md)**:
   - High-level project architecture, migration ledger, upstream base alignment, and core components.
